The Problem & Our Solution

😫

The Problem

Teams need to collaborate on notes and code but juggle between disconnected tools — Google Docs for text, GitHub for code, Slack for comments. No single platform offers real-time co-editing with version history and granular permissions.

✨

Our Solution

Sync Note Net combines rich text (Quill) and code editing (Monaco) with real-time Socket.io collaboration, threaded comments, version control, and flexible sharing — all in one platform.

Real-time Collaboration Flow


// 1. User opens notebook
socket.emit('joinNotebook', { notebookId, guestInfo })

// 2. User types in editor
socket.emit('updateNotebook', { notebookId, content })

// 3. Server broadcasts to room
socket.to(notebookId).emit('notebookUpdated', { content, updatedBy })

// 4. Other users receive update
socket.on('notebookUpdated', (data) => {
  if (data.updatedBy.id !== currentUser.id) {
    setContent(processContent(data.content))
  }
})

// 5. Cursor positions (throttled 50ms)
socket.emit('cursorPosition', { notebookId, position, selection })

// 6. Presence tracking
socket.on('userJoined', (data) => setActiveUsers(...))
socket.on('userLeft', (data) => setActiveUsers(...))

Security Architecture

🔐

Authentication

JWT tokens with configurable expiration. bcrypt password hashing with 10 salt rounds. Account lockout after 5 failed attempts with progressive delay.

🛡️

Middleware Stack

Helmet (security headers), express-rate-limit (100 req/15min), xss-sanitizer, mongo-sanitize, HPP (HTTP parameter pollution protection).

🔑

Access Control

Three permission levels: read, write, admin. Password protection with bcrypt. Guest access with name registration. Per-notebook permission model.
